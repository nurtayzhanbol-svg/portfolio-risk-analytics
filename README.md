# Portfolio Risk Analytics Engine

A small backend for tracking stock portfolios and measuring their risk. You create a portfolio, add holdings, and the API calculates **returns, volatility, Sharpe ratio, max drawdown, Value at Risk and asset allocation** with pandas and NumPy over the stored price history.

```
CSV prices ──load_prices──> PostgreSQL <── FastAPI ──> client
                            (prices, portfolios, holdings)   │
                                                      app/risk.py (pandas / NumPy)
```

The bundled `data/sample_prices.csv` is **simulated**: one year (252 trading days) of random-walk closes for AAPL, MSFT, NVDA, JPM and XOM, generated by `scripts/generate_sample_prices.py` with a fixed seed. It is not real market data.

## Run

Requires Docker with Compose.

```bash
docker compose up -d --build     # postgres + api (loads the sample prices on start)
./scripts/smoke.sh               # creates a portfolio and checks every endpoint
docker compose down -v           # stop and delete data
```

Interactive API docs: http://localhost:8000/docs

## Example

```bash
curl -X POST localhost:8000/portfolios -H 'Content-Type: application/json' -d '{"name": "tech"}'
curl -X PUT localhost:8000/portfolios/1/holdings/AAPL -H 'Content-Type: application/json' -d '{"quantity": 10}'
curl -X PUT localhost:8000/portfolios/1/holdings/NVDA -H 'Content-Type: application/json' -d '{"quantity": 5}'
curl localhost:8000/portfolios/1/metrics
```

```json
{"portfolio_id": 1, "start_date": "2025-01-02", "end_date": "2025-12-19", "days": 252,
 "total_value": 4239.45, "total_return": 0.662529, "annualized_volatility": 0.248336,
 "sharpe_ratio": 2.1808, "max_drawdown": -0.09558, "value_at_risk_95": 0.02243,
 "allocation": {"AAPL": 0.622958, "NVDA": 0.377042}}
```

## API

| Endpoint | What it does |
|---|---|
| `GET /health` | `{"status": "ok"}` |
| `GET /symbols` | every symbol with its latest close |
| `POST /portfolios` | create a portfolio `{"name": "..."}` |
| `GET /portfolios/{id}` | holdings with latest price and value, total value |
| `PUT /portfolios/{id}/holdings/{symbol}` | add a holding or change its quantity `{"quantity": 10}` |
| `DELETE /portfolios/{id}/holdings/{symbol}` | remove a holding |
| `GET /portfolios/{id}/metrics?risk_free_rate=0.03` | return and risk metrics over the full price history |

## Metrics

All metrics assume **buy and hold**: the current quantities are held for the whole period.

| Metric | Formula |
|---|---|
| Daily value | Σ shares × close |
| Total return | last value / first value − 1 |
| Annualised volatility | std(daily returns) × √252 |
| Sharpe ratio | mean(daily return − rf/252) / std(daily returns) × √252 |
| Max drawdown | min(value / running peak − 1) |
| 1-day VaR 95% | −(5th percentile of daily returns), historical method |
| Allocation | holding value / total value, at the latest price |

## Code

| File | What it does |
|---|---|
| `app/risk.py` | the formulas above, as small pandas functions |
| `app/api.py` | FastAPI endpoints and request validation |
| `app/db.py` | table schema and SQL queries (psycopg 3) |
| `app/load_prices.py` | validates a CSV and upserts it into `prices` |
| `scripts/generate_sample_prices.py` | creates the simulated sample data |

## Tests

```bash
python -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
docker compose up -d postgres    # API tests need PostgreSQL; they are skipped without it
.venv/bin/python -m pytest -q
```

- `tests/test_risk.py`: every formula checked against a hand-calculated four-day example.
- `tests/test_load_prices.py`: CSV validation.
- `tests/test_api.py`: endpoints against a real PostgreSQL, in a separate `portfolio_test` database so the app's data is never touched.

## Limitations

- Buy and hold only: no transaction history, cash or rebalancing.
- Historical VaR from one year of data; no stress scenarios.
- Simulated prices, single currency, no dividends or splits.
- No authentication.
